# EchoType v1.5.0

## 中文

- 重构资料库与导入工作台，统一文本、单词本、音频、视频等资料的导入、校对、发布与后续学习流程。
- 新增完整学习闭环：理解、纠错、延迟回忆、迁移练习和每日任务队列，并保留跨页面学习进度。
- 增强导入可靠性，支持可恢复草稿、批量词表、真实文档解析、媒体存储、备份以及冲突保护。
- 升级本地与云端同步可靠性；当云端尚未部署 sync v3 RPC 时自动回退到旧版六表同步，并改进分页、删除传播和错误提示。
- 修复桌面发布包缺少 Supabase 公共认证配置的问题；发布构建会注入并校验所需环境变量。
- 扩展 Windows、macOS、Linux、Web 与 iOS 模拟器的构建、启动和端到端验证覆盖。

本次发布 Desktop：macOS Apple Silicon、Windows x64、Linux x64。保留现有学习数据；不包含 iOS 安装包。

## English

- Rework the library and import workbench into one flow for importing, reviewing, publishing and learning from text, vocabulary, audio and video materials.
- Add a complete learning loop covering comprehension, correction, delayed recall, transfer practice and a persistent daily task queue.
- Improve import reliability with resumable drafts, batch vocabulary, real document extraction, media storage, backups and conflict protection.
- Strengthen local and cloud sync. Installations without sync v3 RPCs now fall back to the legacy six-table path with safer pagination, delete propagation and clearer errors.
- Fix missing Supabase public authentication configuration in desktop releases and validate required values during release builds.
- Expand build, startup and end-to-end verification across Windows, macOS, Linux, Web and the iOS simulator.

Desktop release for Apple Silicon macOS, Windows x64 and Linux x64. Existing learning data is retained; no iOS package is included.
