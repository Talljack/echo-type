# EchoType v1.6.0

## 中文

### 新功能
- 重新设计发音学习页：48 个教学音标点击即播放，搭配 hear 等例词、口型提示、慢速播放和 BBC YouTube 教学链接。内置英式合成语音，无需配置 API；录音和评估保留在独立练习入口。
- 音频导入支持选择语音识别供应商，转写后可边听边校对，并直接开始听力、朗读或输入练习。
- 新增社区学习资源，方便发现英文学习素材。
- 优化每日练习计划，均衡安排学习任务；练习时长和学习日配置统一放入设置页。

### 修复
- 修复桌面设置持久化，更新后保留已保存的配置。
- 有更新时在左下角显示下载入口；检查后无更新则显示“当前已是最新版本”，支持中英文。
- 改善 Google 翻译请求限流后的恢复、缓存和可用 AI 供应商回退。
- 完善桌面托盘图标的回退处理。

Desktop 安装包：macOS Apple Silicon、Windows x64、Linux x64。保留现有学习数据；本次不发布 iOS 安装包。

## English

### Features
- Redesign pronunciation learning with 48 playable teaching entries, example words such as hear, mouth-position tips, slow playback, and BBC YouTube lessons. Bundled British synthetic speech requires no API configuration; recording and assessment remain available in a separate practice view.
- Choose a speech-recognition provider when importing audio, listen while correcting the transcript, then start listening, reading aloud, or typing practice directly.
- Add community resources for discovering English learning material.
- Balance the daily practice queue and move practice-time and learning-day preferences into Settings.

### Fixes
- Preserve saved desktop settings across application updates.
- Show a download entry in the lower-left sidebar when an update is available, and localized “You are up to date” feedback after checking.
- Improve recovery, caching, and configured AI-provider fallback when Google translation is rate limited.
- Improve the desktop tray icon fallback.

Desktop packages: Apple Silicon macOS, Windows x64, and Linux x64. Existing learning data is retained; this release does not include an iOS package.
