# EchoType v1.5.1

## 中文

- 修复 macOS 桌面端更新体验：应用菜单新增“Check for Updates…”，下载完成后会在安装完成后再重启，避免重启后仍运行旧版本。
- 修复 AI 模型配置：支持主动获取/刷新模型列表，避免不必要的模型推荐请求，并让已保存的供应商配置在 Dashboard 加载完成前不会被误判为未配置。
- 完善 AI Chat：工具栏可直接打开资料库选择器和资料搜索，将结果作为当前对话资料，并保持跨页面上下文。
- 修复 Review 空队列进度显示与单词本练习的重复输入区域。
- 扩展端到端回归：覆盖导入资料后完整完成听、朗读、口语、输入、Dashboard 统计和 Lesson Review 的学习闭环。

本次发布 Desktop：macOS Apple Silicon、Windows x64、Linux x64。保留现有学习数据；不包含 iOS 安装包。

## English

- Improve the macOS desktop update flow: add “Check for Updates…” to the application menu and restart only after installation completes, avoiding a relaunch into the old version.
- Improve AI model configuration: allow explicit model-list fetch/refresh, avoid unnecessary model-recommendation requests, and prevent saved providers from being treated as unconfigured before Dashboard hydration finishes.
- Complete AI Chat tooling: open the library picker or material search from the toolbar, apply a selected item as chat context, and preserve that context across navigation.
- Fix empty-review progress presentation and the duplicate input area in vocabulary practice.
- Expand end-to-end regression coverage for the complete learning loop: import material, complete listening, read-aloud, speaking and typing, verify Dashboard activity, then finish Lesson Review.

Desktop release for Apple Silicon macOS, Windows x64 and Linux x64. Existing learning data is retained; no iOS package is included.
