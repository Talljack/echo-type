# EchoType Desktop v1.4.0

## 中文

- 修复 Windows 启动卡住约 30 秒后退出的问题（#105）。
- 统一课程与练习流程，整理学习导航，优化今日计划和 Activity 展示。
- 新增 Windows、macOS、Linux 打包启动检查，以及 Web、iOS 模拟器启动检查。
- 修正自动更新的安装包及签名匹配；不再向 Intel Mac 提供 ARM 更新包。
- 包含依赖安全更新。保留现有学习数据，无需重新导入资料。

桌面安装包：Windows x64、macOS Apple Silicon、Linux x64（deb / AppImage）。本次不发布 iOS 安装包或 Intel Mac 安装包。

## English

- Fix the Windows startup hang/crash caused by the bundled Node entry path (#105).
- Unify courses and practice flows, simplify learning navigation, and improve the daily plan and activity view.
- Add packaged desktop startup checks plus production Web and iOS simulator coverage.
- Correct updater assets/signatures and stop advertising ARM updates to Intel Macs.
- Include dependency security updates. Existing learning data is retained.

Desktop builds: Windows x64, macOS Apple Silicon, Linux x64 (deb / AppImage). No iOS or Intel Mac installer is published in this release.
