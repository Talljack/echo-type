# EchoType 导入设计 V2

交付物：`index.html` 为交互设计稿。所有内容、进度与按钮结果均为演示，不上传文件、不调用 AI、不保存真实资料。

## 1. 产品结构

资料库只有一个“添加材料”入口。桌面使用最大 1120px 的聚焦弹窗，手机使用全屏弹窗。输入来源为文件、粘贴文本、链接；保存结果仍为六种材料：词书、视频、阅读（含英文书籍）、对话、句集、场景。音频作为输入，转写后生成句集或场景。

主流程：添加来源 → 处理材料 → 校对与整理 → 开始学习。纯文本无需上传，直接进入校对。只有已校对的内容进入资料库。

## 2. 格式与支持边界

| 输入 | 现有基础 | V2 处理设计 | 状态 |
| --- | --- | --- | --- |
| TXT / MD / TEXT | 提取文本 | 保留段落、标点；建议文章、对话、句集或场景 | 已有解析，需整合新交互 |
| EPUB | 提取章节 | 目录、章节预览、选择章节、统一书名和标签 | 已有解析；选择章节为新增 |
| PDF / DOCX | 提取正文 | 标记提取警告、保留可获得的来源位置 | 已有解析；可靠页码锚点需补充 |
| CSV / TSV | 词表导入 | 列映射、行级报错、精确重复跳过、不同释义保留 | 已有解析；交互式列映射为新增 |
| SRT / VTT | 提取字幕 | 保留时间轴、调整偏移，可绑定视频 | 已有解析；自动配对为新增 |
| MP4 / WebM / AVI | 媒体上传 | 字幕优先；无字幕时用户确认 AI 转写 | 已有基础 |
| MP3 / WAV / M4A / OGG / FLAC | 音频转写 | 确认服务商后转写，再整理成句集或场景 | 已有基础 |
| 粘贴文本 | 直接输入 | 保留换行；识别词表/对话；默认建议可修改 | 已有文本；词表自动识别为新增 |
| 网页 / YouTube | 正文/字幕提取 | 分清网络失败、权限限制、提取失败；同任务补充正文/字幕 | 已有基础；完整错误分类及任务补充为新增 |
| XLSX / JSON | 未接入统一导入 | XLSX 选择工作表并映射列；JSON 明确支持的字段结构 | 规划，不标为已支持 |
| JPG / PNG / WEBP、扫描 PDF | 未接入统一 OCR 流程 | OCR 后必须预览纠错，可转换为阅读或词表 | 规划 |

当前代码上限：文档 20 MiB、词表 20,000,000 字节/100,000 行、字幕 10 MiB、媒体 25 MiB。正式 UI 应统一单位并显示每种格式的实际限制。设计不靠提升数字宣称支持大文件；大媒体需要独立上传、分段处理和服务端任务能力后再提高限制。

旧 DOC / XLS、MOBI / AZW、加密文件、ZIP：显示具体转换方法；不进入无限重试。XLS 可转 XLSX/CSV，旧文档可转 DOCX/PDF。目录选择和压缩包展开不纳入首版。

## 3. 添加来源

- 大拖放区、可点击选择、拖放与键盘等价。移动端调用系统文件选择器。
- 批量文件形成队列；每个文件独立检查格式、真实大小、空文件和可用存储。单项错误不阻断其他项。
- 同名视频与字幕建议配对，用户可修改；不默默绑定。
- 粘贴内容默认只要求正文，标题、难度、标签放在校对阶段。切换输入方式保留各自草稿。
- 文件已存在时展示“打开已有任务 / 作为新材料导入”；重复内容不能静默吞掉用户操作。

## 4. 处理与恢复

任务状态：待处理、上传中、提取中、待确认 AI、可校对、失败、已发布、已取消。显示实际阶段、已完成文件数、可测的字节进度；未知耗时不编造百分比。

AI 转写与 OCR 明示服务商、发送内容及可能费用，确认后开始。没有可用配置则提供设置入口及字幕/文本替代路径。

客户端处理需要页面保持打开；关闭弹窗可以继续，刷新或退出后恢复至可重试状态。只有部署了后台任务的环境才显示“离开页面后继续处理”。草稿保存状态分清“已保存 / 保存中 / 保存失败”；失败时保留输入。

网络、限流、内容受限、文件损坏、解析空结果、没有字幕、账户切换、磁盘空间不足分别处理。尤其“所有抓取方法失败”只能称为“未获取到字幕”，不能推断视频本身没有字幕。失败任务可补充文本/字幕，保留原链接与任务身份。

## 5. 校对与整理

三列布局：178px 内容目录 / 可伸缩正文 / 246px 材料设置。手机按目录、正文、设置排列，底部操作始终可见。编辑期间保留光标、章节位置与未提交标签文本。

- 阅读/书籍：章节目录、原文对照、段落编辑、章节选择，发布时保留整本书结构。
- 词书：可编辑表格；单词/释义必填，音标/例句/构词信息选填；逐条展示错误和重复。
- 视频：播放器和时间轴字幕联合编辑，时间单位统一为秒，点击字幕定位视频。
- 对话：说话人及轮次编辑，增删、排序。
- 句集：逐句编辑，拆分/合并，保留标点。
- 场景：背景、角色、目标必填，参考表达选填。

右侧统一提供标题、材料类型、难度、标签。标签是明确可见的字段，支持常用标签、自定义、键盘添加/删除。保存时规范化标签；输入过程中保留逗号、空格等未提交文本，避免连续输入第二个标签失败。词书同样需要材料级标签设置，不能仅依赖导入程序生成系统标签。

更改类型可能丢失结构时展示影响说明并可撤销。原文件和原始文本只读保留，校对稿单独保存。来源与高级设置折叠，但标签不隐藏。

## 6. 发布与学习

一个动作原子保存：校对内容、章节关系、标签、原始来源、材料类型和课程入口。双击、超时后重试不会重复创建。发布前最后校验空章节、缺失释义、场景必填字段、字幕时间顺序。

成功页突出“开始第一课”，次级“继续添加”。加入今日计划为可选，不默认改变学习计划。阅读/视频等进入理解 → 输出 → 纠错 → 复习 → 运用；词书进入释义回忆 → 拼写 → 语境运用 → 间隔复习。失败任务仍在队列中可恢复。

## 7. 视觉规范

沿用 EchoType：Poppins 标题 / Open Sans 正文，缺字回退系统中文字体；主色 #4F46E5，浅靛蓝 #EEF2FF，正文 #202541。主体白色，目录和设置面板使用灰蓝色差。圆角为 6px 标签、8px 控件、12px 投放区、16px 弹窗。正文不再叠套卡片。主要按钮 42px 以上，点击缩放，支持减弱动效和可见键盘焦点。

原型采用独立 HTML + 原生 CSS。正式新版使用独立 CSS Module 按原型尺寸与布局实现，隔离旧导入界面的样式；不新增 UI 框架。

## 8. 实施与验收

1. 先统一三类输入及六类编辑器，补齐所有类型的标题/标签/难度，验证刷新恢复和发布后检索。
2. 接通任务内失败恢复、字幕配对与批量任务，验证部分失败、重复发布、账户切换。
3. 再扩展 XLSX / JSON / 图片与扫描 OCR；解析器和真实样本通过后才开放文件选择器支持列表。

## 9. 本轮实现与数据兼容

本轮接入正式资料库弹窗：四步进度、大文件投放区、批量选择与独立任务、正文/设置分栏、章节勾选、原文对照、可编辑词表、各入口的标签与难度、失败链接补充文本或字幕。任务仍需逐个打开处理，并非后台自动批处理。

`ImportJob` 增加可选的 `batchId`、`tagsText`、`excludedBlockIds`、`supplementalText`。这些字段不参与索引，无需增加 Dexie 表或升级本次 schema；旧任务缺省为全部章节、原有标签。已发布内容继续使用 `contents` / `books`，不改学习记录 ID、不清空数据库。原文件、原始提取结果与校对稿分开保留；章节排除只影响发布。词书继续使用旧去重指纹，避免升级后重复导入已有词书。

尚未实现：XLSX / JSON / OCR 解析、交互式列映射、同名字幕自动配对建议、后台批处理、可靠 PDF 页码锚点和重复来源的“另存为新材料”。原型中的这些能力不代表当前产品已具备。网络链接和 AI 转写仍依赖来源可访问性与用户配置，不能承诺所有网站都能抓取。
4. 大文件后台上传为单独工程，不与 UI 限额文案混同。

验收用真实文件覆盖每个格式，检查导入后正文、标签、章节、时间轴及学习入口；外部链接记录真实抓取结果，模拟响应只验证交互。平台分别验证浏览器、Tauri 的文件和媒体访问，以及 iOS 系统文件选择器。此设计稿不是上述功能已实现的证明。

## 10. 按设计稿重建界面

正式入口现在只渲染 `MaterialImportV2`，不挂载旧导入 UI。来源选择、处理队列、目录/正文/属性三栏校对及完成页均为新组件；解析与持久化通过无界面的 hook 连接。保留原始资料和既有任务，不迁移或删除学习记录。完成页的今日计划入口会创建真实任务，词书使用背词任务。

本轮生产构建、TypeScript 检查通过；新版流程在 Chromium 与 WebKit 下 14 项测试通过，相关单元测试 36 项通过。覆盖来源界面、文件到学习入口、CSV 校对、标签、手机布局、媒体转写确认和链接失败后的补充文本。外部提取接口使用模拟响应验证交互，不能视为所有网站抓取、全部格式解析或 Windows/iOS 真机验证通过。第 9 节未实现能力仍然适用。
