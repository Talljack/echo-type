# 导入与学习全链路复测（2026-09-16）

结论：六种材料均有导入后学习的通过证据，但不能签署“全部来源、全部格式、全部平台完整可用”。远程 PDF、自动语音转写与下述覆盖缺口仍需验收。

## 执行结果

- 全量 Vitest：168 个文件通过、1 个跳过；1015 项通过、3 项默认跳过。
- 单独启用本地 Ollama：3/3 真实调用通过（结构化输出、句子整理、场景整理），不是模拟结果。
- 首轮 Chromium / WebKit 验收：88 项中 83 通过、5 失败。没有删除失败项或以重试抹掉首轮结果。
- 新增实际导入后的五阶段学习：文章、对话、句子、场景共 8/8 通过；视频另 2/2 通过。包括刷新后保留完成进度。
- TypeScript `pnpm exec tsc --noEmit` 通过。本轮没有重新构建生产包，运行的是前轮构建的当前实现。

## 首轮失败的复核

1. **远程 PDF：两浏览器失败，尚未通过。** W3C 样本没有进入可校对状态。既往接口诊断为源站 / 网络路径拒绝。本地 PDF 解析成功不能替代此项。
2. **英文书籍 URL：WebKit 首轮失败。** Gutenberg 文本链接单独重跑两个浏览器均通过；记录为真实外网存在波动，不能保证所有书籍链接成功。
3. **字幕单位：一项测试时序错误。** 原断言只等待“校对”按钮可见，在尚不可用时读取任务，得到空 blocks。改为等待按钮可用后，两个浏览器各重复三次，6/6 通过。保留原毫秒转秒断言。
4. **草稿恢复：一项刷新发生在保存完成之前。** 复跑原步骤仍能复现。源码的“返回来源”处理会等待异步保存；测试点击后立即刷新会中断等待。补充等待返回完成，再刷新恢复标题和标签，两个浏览器各三次，6/6 通过。**保存进行中强制关闭 / 刷新的耐久性不计为通过**；没有通过延时等待宣称强制中断已修复。

## 已测异常与恢复

空文件、不支持的 XLSX、超限文件、重复文件与新文件混合、标题与标签正常保存后的恢复、历史 YouTube 时间轴迁移与备份、原材料保留、音频转写失败时保留原文件。部分 UI 异常和迁移测试使用模拟 API / 数据，不能与真实来源成功混算。

## 未通过 / 未完整覆盖

- 音频自动转写仍没有成功全链路证据；本机 llama3.2 是文本模型，不能代替 STT。WAV 仅验证失败后的保留与提示。
- MP3、M4A、OGG、FLAC、WEBM、AVI 未逐格式执行成功的真实导入到学习；不能仅凭扩展名支持宣称已验收。
- 扫描 PDF / OCR、XLSX 等不属于本轮已支持且通过的格式；XLSX 验证的是明确拒绝。
- 五阶段学习已覆盖六类材料；不代表所有听说读写独立模式、真实麦克风识别、发音评分、TTS 提供商已逐项实测。
- macOS 上的 Chromium / WebKit 不等于 Windows 桌面、Tauri 安装包或 iOS 真机验收。
- 测试使用隔离浏览器数据库，没有更改用户当前浏览器的资料或默认 AI 配置；未执行云同步 / 跨账号实际验收。
