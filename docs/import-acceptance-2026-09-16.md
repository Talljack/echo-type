## 阻断问题与证据

### P0：DOCX 对外宣称支持，但正式解析失败

错误：`DOMParser.parseFromString: the provided mimeType "undefined" is not valid.`

依赖证据：mammoth 1.11.0 的 XML 包装器调用 `domParser.parseFromString(string)`，未传 MIME；当前锁文件将 `@xmldom/xmldom` 解析为 0.9.12，其 API 要求 MIME。项目宽泛的安全 overrides 允许了这一跨版本组合。应在不降低安全修补要求的前提下修复兼容组合，并保留真实 DOCX 回归测试。

### P0：YouTube 字幕时间单位契约不一致

`src/app/api/import/youtube/route.ts` 的 direct 分支将秒乘 1000；`src/components/import/use-material-preparation.ts` 又直接把 `offset` 赋给以秒为单位的 `timeStart`。课程播放器也按秒解释起点。需统一 API、备用提取分支、导入保存和已有错误时间戳的处理，不能只改显示文案。

真实用例记录：首条 `timeStart = 1360`。字幕文本、发布和课程入口成功不能抵消这个定位错误。

### P1：链接与 AI 转写错误不能指导用户恢复

当前真实环境看到了 `fetch failed` 和 `Forbidden`。任务和原件可以保留，但这些提示没有说明网络、授权或服务商拒绝的区别；成功 AI 转写、音频自动整理成场景/句集仍未验证。需要给出对应的重试、检查服务商设置、补充字幕/文本入口和清晰状态，不能显示一个泛化错误就算完成。

## 导入后如何使用（已验证部分）

1. 在学习材料页选择唯一导入入口，上传文件、粘贴原文或链接。
2. 完成处理后进入校对：检查正文/章节/词表，设置标题、材料类型、难度和标签；场景补齐角色与沟通目标。
3. 加入资料库。完成页可选加入今日计划，点击“开始第一课”；也可稍后从学习材料页打开。
4. 阅读和书籍：理解主旨并填写原文依据 → 原创输出 → 修改回答并说明改进 → 到期回忆与自评 → 在新情境造句运用。
5. 词书：释义回忆 → 对照答案与分级 → 拼写纠错 → 构词提示练习 → 新情境例句、收藏与安排复习。
6. 本地视频：使用保留的视频和字幕学习；本轮验证实际播放。YouTube 定位需先修复时间轴问题。

英文书籍五阶段在 Chromium 和 WebKit 通过。延迟复习由测试数据库回拨学习记录时间触发，不改用户数据，也不声称等候了真实的一天。词书闭环在两个引擎通过，包含刷新恢复回答、错误拼写不能评为 Good、构词参考、例句去重约束和收藏。

### Groq 与 Ollama

- Groq 无认证的 `/openai/v1/models` 也返回 Cloudflare HTTP 403、正文 `Forbidden`；既往携带凭据的转写请求同样为 403。直连在 TLS 握手阶段失败。因此不能据此判断密钥无效，更不能宣称 Groq 服务关闭。官方将 401 列为认证失败、403 列为权限限制：[错误文档](https://console.groq.com/docs/errors)。本轮不再依赖 Groq。
- 本地 `127.0.0.1:11434` 可用，使用已安装的 `llama3.2:latest`，不使用带远程宿主的 cloud 模型，不上传私人资料。
